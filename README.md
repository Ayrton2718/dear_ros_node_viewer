# Dear RosNodeViewer
## About
- Visualize ROS2 node diagram
- Support the following sources:
  - *architecture.yaml* generated by [CARET](https://github.com/tier4/caret)
  - *rosgraph.dot* generated by rqt_graph
  - running ROS graph analysis
- Export to interactive Mermaid diagrams (HTML format)

## Requirements
- Ubuntu 20.04 or 22.04
  - graphviz is required
- optional: ROS 2 Galactic or Humble if you need runtime ROS graph analysis
  - e.g., `sudo apt install ros-humble-rqt-graph` , `sudo apt install ros-humble-desktop`
- Not tested in Windows / Mac

## Get Started
```sh
# Install requirements
sudo apt install graphviz

# Install Dear RosNodeViewer
pip install dear-ros-node-viewer

# Download sample graph
wget https://raw.githubusercontent.com/iwatake2222/dear_ros_node_viewer/main/sample/architecture_autoware.yaml

# Run Dear RosNodeViewer
dear_ros_node_viewer architecture_autoware.yaml
```

- Quick operation guide:
  - Middle button drag: move graph area
  - Mouse scroll: zoom in/out (zoom function is tentative)

## Mermaid Export Feature

Dear RosNodeViewer can export ROS node graphs to interactive Mermaid diagrams in HTML format. This feature allows you to:
- View and share ROS graphs without running the Dear RosNodeViewer application
- Create interactive web-based diagrams that can be opened in any web browser
- Navigate through individual nodes and their connections
- Organize large graphs by namespaces

### Basic Usage

#### 1. Export Mermaid HTML from Architecture File

Menu -> Export -> "Export to Mermaid"

```bash
# Run with your architecture YAML file
python3 main.py /path/to/architecture.yaml
```

This will generate a timestamped Mermaid HTML file in the current directory:
- `ros_graph_YYYYMMDD_HHMMSS.mermaid.html`

#### 2. Create Interactive Node-Centric Diagrams

Use the `generate_node_page.sh` script to create an interactive diagram with clickable nodes:

```bash
cd mermaid-tools
./generate_node_page.sh ../ros_graph_YYYYMMDD_HHMMSS.mermaid.html
```

### Output Files

The Mermaid tools generate three types of output files:

#### 1. Main Interactive Graph (`ros_graph_linked.mermaid.html`)
- Full ROS node graph with clickable node links
- Click on any node to view its detailed connections
- Located in the current directory

#### 2. Individual Node Pages (`nodes/*.html`)
- One HTML file per node showing:
  - Incoming connections (subscribers)
  - Outgoing connections (publishers)
  - Connection statistics
  - Links to connected nodes
- Example: `nodes/planning_scenario_planning_lane_driving_behavior_planning_manager.html`

#### 3. Namespace Subgraphs (`*.mermaid.html`)
- Separate diagrams for each namespace (e.g., `/planning`, `/control`, `/sensing`)
- Shows nodes within each namespace with connections to other namespaces
- External namespaces are collapsed for clarity
- Examples:
  - `planning_scenario_planning.mermaid.html`
  - `control.mermaid.html`
  - `sensing.mermaid.html`
